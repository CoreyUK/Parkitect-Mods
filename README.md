# Parkitect Mods

A source collection for Parkitect mods.

## Included mods

- [Dynamic Ride Pricing](DynamicRidePricing/README.md) - Automatically adjusts ride prices using excitement, queue demand, weather, and decaying popularity.
- [Special Guest Visits](SpecialGuestVisits/README.md) - Adds occasional inspectors, reviewers, influencers, and auditors with park-wide consequences and rewards.

Each directory contains only the mod source, project file, and README. Release archives, compiled binaries, thumbnails, Nexus metadata, Workshop files, and other assets are intentionally excluded.
